Belum ada PASS visual penuh untuk source aplikasi terkini. Angka di atas adalah cakupan berkas layar, bukan persentase pekerjaan proyek selesai. Beberapa berkas memakai route yang sama atau komponen re-export; tiap route masih mempunyai banyak state.

Bukti dan batas pemeriksaan

239 source layar diparse, 89 layout dan 649 berkas UI/config dicatat hash. Terdapat 16 frame dengan gambar acuan. Empat belas pasangan Figma–preview historis ditinjau; satu pasangan interim Stok Akhir pemilik dilihat sebelum handoff. Tidak ada eksekusi ulang seluruh aplikasi atau pengujian native dalam audit ini.

Metadata halaman cached terpotong pada marker truncation; 126 kandidat frame terlihat dari metadata parsial dan ringkasan tersimpan, bukan seluruh file Figma. Beberapa PNG hanya berukuran 124–370 px lebar akibat downscale; tidak dihitung sebagai acuan pixel penuh.

Nama frame yang menyesatkan diperiksa melalui dokumentasi/teks anak. Jumlah stok, nama record, nominal, tanggal dan jumlah item boleh berbeda karena data dinamis. Screenshot hanya mencakup viewport/keadaan tertentu. Perbedaan copy placeholder yang diperbaiki dicatat tersendiri.

Akses langsung Figma belum tersedia pada sesi QC: tool tidak callable, plugin belum terpasang pada pemeriksaan awal, CLI tanpa MCP dan URL web tidak dapat dibaca. Untuk lanjut ke semua frame, pasang plugin Figma dan hubungkan akun yang memiliki akses ke file Rapido.

Temuan untuk koreksi

QC-FIGMA-001 — Ikon dan warna kategori FAQ berbeda

Frame: 1:19624 · Status: perbedaan source, koreksi diperlukan.

Screenshot Figma memakai ikon outline berbeda; kategori katalog berwarna magenta dan waiter ungu. FaqCard terkini memakai tag dan bell-concierge primary/biru serta registry ikon pengganti.

Koreksi: Ambil SVG/tint resmi dari frame FAQ, simpan aset lokal, gunakan primitive/semantic token yang disetujui; pertahankan perilaku expand/search.

Pemilik: Codex-3 / pemilik Bantuan; perubahan registry/token bersama harus dikoordinasikan

Verifikasi: Screenshot komponen aktual pada state kategori sama; enam ikon/tint cocok, tidak ada perubahan perilaku, 320/390/native tetap terbaca. Source: components/feature/support/FaqCard.tsx.

QC-FIGMA-002 — Bentuk tombol Hubungi Support berbeda

Frame: 1:19624 · Status: perbedaan source, koreksi diperlukan.

Figma menampilkan tombol persegi bersudut kecil. Caller FAQ memakai Button size xs tanpa varian bentuk; primitive Button default rounded-full. Screenshot historis memperlihatkan bentuk pill.

Koreksi: Gunakan varian bentuk semantic yang sesuai frame pada caller ini; jangan mengubah default global atau menambah override radius sembarang.

Pemilik: Codex-3 untuk caller; pemilik Button/PM untuk varian opt-in

Verifikasi: Tombol cocok bentuk/ukuran acuan, area tekan tetap layak, default caller lain tidak berubah dan dialog kontak belum tersedia tetap jujur. Source: app/(no-layout)/manage/faq/index.tsx; components/ui/button/index.tsx.

QC-FIGMA-003 — Angka ringkasan detail penyesuaian stok kehilangan warna

Frame: 1:13605 · Status: perbedaan source, koreksi diperlukan.

Figma memberi warna warning/destructive/success pada tiga total. StockOperationDetail mengirim tone yang tepat, tetapi InventoryMetrics menerapkannya pada ikon/latar saja; Text untuk item.value memakai foreground tanpa tone. Screenshot historis memperlihatkan tiga angka gelap.

Koreksi: Tambahkan opsi semantic warna nilai pada komposisi metrik penyesuaian; pertahankan default ringkasan/transfer dan perhitungan stok dinamis.

Pemilik: Senior5 / pemilik Inventory; pisahkan dari scope Stok Akhir yang aktif

Verifikasi: Tiga nilai berwarna sesuai acuan, label tetap terbaca pada 320/390, satuan campur tetap tidak dijumlah dan caller lain tetap sesuai desain masing-masing. Source: components/feature/inventory/StockOperationDetail.tsx; components/feature/inventory/InventoryUi.tsx.

QC-FIGMA-004 — Ikon metadata daftar transfer dan pembelian terlalu biru

Frame: 1:12059, 1:14945 · Status: perbedaan source, koreksi diperlukan.

Figma memakai ikon metadata muted/abu-abu. InventoryMetadata terkini selalu memanggil InventoryIcon tanpa tone; default tone primary. Screenshot historis memperlihatkan ikon metadata biru.

Koreksi: Sediakan tone muted secara semantic dan pilih untuk metadata pada kedua frame; jangan mengubah semua ikon biru global.

Pemilik: Senior5 / pemilik Inventory dan ikon semantic

Verifikasi: Ikon metadata muted dan bentuk sesuai asset acuan; link ID/action tetap primary, semua caller InventoryMetadata ditinjau ulang. Source: components/feature/inventory/InventoryUi.tsx.

Urutan tindak lanjut

  1. Hubungkan Figma dan ambil full context/screenshot/aset untuk 45 layar yang mempunyai frame tercatat tetapi gambar belum lengkap, lalu sahkan 10 kandidat dan petakan 159 berkas yang belum dipetakan.
  2. Sepuluh berkas dengan panduan UI tanpa frame tercatat perlu frame/keputusan desain yang sah. Jangan menyebutnya telah cocok Figma.
  3. Pemilik Bantuan/Inventory koreksi 001–004; pemilik shared component menyediakan varian semantic opt-in. Stok Akhir menunggu handoff final.
  4. Capture source terkini pada state yang sama: loading/error/empty/list/detail/tambah/edit/filter/modal bila berlaku, viewport 320/390/landscape, web dan native. Pertahankan regresi perilaku dan data dinamis.
  5. QC keluarkan keputusan per frame dan hash; PM menilai integrasi/push setelah gate terkait terpenuhi.

Execution Profile & Operator Tips: High karena cakupan seluruh layar. Kerjakan per modul: acuan lengkap → koreksi pemilik → QA perilaku → QC screenshot/hash → PM. Header tetap pada layout; gunakan semantic primitive dan hindari mengambil source pemilik aktif.
