### Common Components Folder

Used for generic components that can be used across multiple features in Rapido.

| Component | Path | Description |
| --- | --- | --- |
| **`SingleSelect`** | `@/components/common/SingleSelect` | Tactile single-selection picker using bottom Actionsheet with floating cards, active checkmark badges, search filter, and haptic feedback. |
| **`MultiSelect`** | `@/components/common/MultiSelect` | Multi-selection picker with bottom Actionsheet, select-all toggle, search filter, and chip pills. |
| **`SearchBar`** | `@/components/common/SearchBar` | Standard search input with debounce and clear button. |
| **`Card`** | `@/components/common/Card` | Standard content card (`rounded-xl shadow-main p-4 bg-white`). |
| **`BouncyPressable`** | `@/components/common/BouncyPressable` | Interactive pressable wrapper with spring scale animation and haptic feedback. |
| **`Text`** | `@/components/common/Text` | Strictly enforced semantic typography component (`size="small" \| "normal" \| "body"`, `w="regular" \| "medium" \| "semibold" \| "bold"`). |
| **`BottomActionButton`** | `@/components/common/BottomActionButton` | Sticky bottom CTA button bar for screens. |
| **`SortActionSheet`** | `@/components/common/SortActionSheet` | Quick sort options bottom sheet. |
| **`AlertModal`** | `@/components/common/AlertModal` | Standard alert/error confirmation modal. |
| **`SuccessModal`** | `@/components/common/SuccessModal` | Success feedback modal. |
| **`DeleteConfirmModal`** | `@/components/common/DeleteConfirmModal` | Destructive action confirmation modal. |
| **`ImageUploader`** | `@/components/common/ImageUploader` | Image picker and upload preview. |
| **`Wrapper` / `AnimatedWrapper`** | `@/components/common/Wrapper` | Standard screen container with safe areas and optional scroll-to-top FAB. |
